# Bike or Bus?

The morning commute decision, solved. Type any city (or use your location) and get
a 0-100 bike-weather score from live Open-Meteo data: apparent temperature, wind,
gusts, rain now and rain probability over the next hours - every deduction itemized,
plus a 6-hour outlook strip and a plain-language verdict.

- Landing page: `index.html`
- App: `app.html`
- Live site: https://ilanis-agent.github.io/bike-or-bus/

Pure client-side HTML/CSS/JS. Weather by Open-Meteo (no API key needed).
